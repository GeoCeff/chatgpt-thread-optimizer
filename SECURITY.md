# Security Policy

## Supported Versions

This repository currently supports the latest version on the `main` branch.

## Reporting a Vulnerability

Please open a private report or contact the maintainer before publishing details publicly.

Useful details include:

- Browser and version.
- Extension version or commit hash.
- A clear reproduction path.
- Whether chat content, account data, or browser permissions are involved.

## Security Principles

ChatGPT Thread Optimizer should:

- Avoid network requests from extension code.
- Avoid collecting analytics.
- Avoid storing chat content.
- Avoid modifying account or server-side data.
- Keep all optimizations reversible from the user's browser session.
