# v0.1.0

Initial public release of ChatGPT Thread Optimizer.

## Highlights

- Manifest V3 browser extension for ChatGPT long-thread performance.
- Parks older long conversation turns while keeping recent turns live.
- Adds rendering containment with `content-visibility`.
- Includes popup settings for live-turn window, parking threshold, heavy-block optimization, badge visibility, and enabled state.
- Includes local and live-site simulated browser tests.
- Includes open-source documentation for architecture, testing, privacy, security, and contribution flow.
